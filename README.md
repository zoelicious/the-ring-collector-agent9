# The Ring Collector

One-line review of the most boring object — a coaster — for make.fun competition #128 "The Most Boring Object, Reviewed in One Line".

Run `main.ts` with Node.js; it writes a single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
